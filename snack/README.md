# 控制台贪吃蛇游戏

一个用C语言编写的经典贪吃蛇游戏，运行在控制台/终端中。

## 编译和运行

```bash
# 编译
make

# 运行
./snake
```

或者直接使用gcc编译：
```bash
gcc -o snake snake.c
./snake
```

## 游戏控制

- **W** 或 **↑**: 向上移动
- **S** 或 **↓**: 向下移动
- **A** 或 **←**: 向左移动
- **D** 或 **→**: 向右移动
- **Q**: 退出游戏

## 游戏规则

1. 控制蛇吃掉食物（*）来增长蛇身
2. 每吃一个食物得10分
3. 撞到墙壁或自身会导致游戏结束
4. 蛇不能直接反向移动（例如正在向右移动时不能直接向左）

## 游戏元素

- `@`: 蛇头
- `o`: 蛇身
- `*`: 食物
- `#`: 边界墙壁

## 游戏特点

- 平滑的终端控制
- 实时输入处理
- 分数和长度显示
- 经典贪吃蛇玩法

## 系统要求

- Linux/macOS系统
- GCC编译器
- 支持ANSI转义序列的终端
